# Glyph 1.4.1 release verification

Prepared on 11 October 2026: version `1.4.1+13`, arm64 APK versionCode `2013`.
Adds 27 CC0 animations and seven reviewed dependency updates. This is the
first release with the dedicated release key and old-to-new signing lineage.

## Candidate checks

- The dependency merge passed analysis, all 1,499 Flutter tests, Android debug
  builds and native Android tests. Live-controller tests were skipped.
- Release preparation passed analysis and all six What's new tests. The
  unsigned arm64 release build passed with Gradle 9.8.0 and AGP 9.4.1.
- The production catalog smoke check verified revision 4, its signature and
  payload hash, all 1,236 looks, HTTP 304/cache reuse, offline recovery and the
  minimum app-version gate.
- The two Fastlane changelogs (`13.txt`, `2013.txt`) are identical and each
  contains 222 characters, below the 500-character limit.
- The release workflow parses as YAML; both extracted signing shell scripts
  pass `bash -n`. Preflight accepts complete material and rejects each of the
  nine signing secrets individually when absent.
- Local execution of the workflow's signing logic rejects the wrong release
  key and invalid lineage. For macOS, local testing selected build-tools
  36.0.0 directly and used Python's scoped temporary-directory cleanup; the
  signing arguments and certificate assertions were unchanged.
- The signed candidate verifies with the existing certificate on API 24–27
  and the dedicated certificate on API 28–32 and the full supported range.
  The APK's embedded lineage contains both expected certificates in order,
  permits installed data and permissions, and disallows rollback.
- An in-place update on the connected Android API 37 phone succeeded over
  Glyph 1.3.6 (`2011`, old certificate). The new version is `1.4.1` / `2013`;
  app ID `10476`, original install date and all 15 granted permissions were
  preserved. No uninstall or app-data reset was used.

The workflow now requires all nine signing secrets and pins both certificate
fingerprints. Missing rotation material cannot publish an old-key-only APK.
See [SIGNING.md](SIGNING.md) for key storage, rotation and recovery.

## Limits

Android 7–8 and Android 9–12 were verified with apksigner, not physical
installation tests. The API 37 update confirms modern Android accepts the
rotation; it does not constitute a full app or controller QA pass. No frames
were sent to a real controller during these checks.

The reported intermittent Ocean flash remains unconfirmed and unresolved.
This release does not change playback logic or claim to fix that report.

The release commit must pass CI before its tag is pushed. After publication,
download the CI-built APK and verify its checksum, version and both signing
identities again.
